# 지식 명칭 감사 현황

기준 시각: 2026-08-25 KST  
대상: 활성 청크 90,293개  
원본 로그: `logs/knowledge-audit.jsonl`

## 1. 감사 목적

수집된 커뮤니티 데이터에서 검수 약어가 어떻게 사용되는지 확인하고, `약어(확장)` 또는
`약어 = 확장`처럼 원래 이름을 명시한 표현이 지식 그래프의 공식 아이템명과 다른지 탐지한다.

커뮤니티 사용 빈도만으로 canonical relation을 자동 추가하거나 수정하지 않는다. 탐지 결과는
검수 후보이며, 공식 문서 확인과 운영자 검토를 통과해야
`item-abbreviations-v1.json` 또는 `game-terms-v1.json`에 반영할 수 있다.

현재 등록된 13개 약어에 대해 **canonical 명칭과 다른 명시적 이름 확장 후보는 0건**이다.
`놀러긍` 문자열도 활성 청크에서 0건이다.

`추옵`의 canonical target은 넥슨 공식 가이드의 `추가 옵션`, `아크이노`의 target은
`아크 이노센트 주문서`다. 새 검수 약어 `유챔`과 `데티`는 각각 `유니온 챔피언`,
`데스티니 무기`에 연결된다. corpus에서 전체 명칭의 출현이 적더라도 빈도로 target을 바꾸지 않고
source가 명시된 graph relation을 유지한다.

이 결과는 “모든 커뮤니티 용어가 정확하다”는 뜻이 아니다. 괄호나 등호 없이 문장 속에서 잘못
풀어 쓴 표현과 아직 등록되지 않은 약어는 현재 정확 비교 대상이 아니다.

## 3. 추가 검토가 필요한 관찰 surface

자동 감사는 약어가 다른 글자와 붙은 형태도 별도로 집계하되 공식 alias로 자동 인정하지 않는다.

| 관찰 표현 | 포함 활성 청크 | 현재 판단 |
|---|---:|---|
| 놀긍혼 | 32 | `놀긍`과 같은 아이템을 가리키는 추가 약어 후보, 수동 검수 필요 |
| 놀긍혼주문서 | 6 | `놀긍혼`의 복합 표현 후보 |
| 프악공마 | 6 | 공격력/마력 주문서를 함께 지칭할 가능성이 있어 단일 item alias로 등록하면 안 됨 |
| 프펫공마 | 9 | 공격력/마력 주문서를 함께 지칭할 가능성이 있어 단일 item alias로 등록하면 안 됨 |

`놀긍작`, `놀긍떡작`, `프악공작`, `프펫공작` 등은 아이템명을 새로 풀어 쓴 표현이 아니라
강화 행위를 뜻하는 합성어이므로 alias 후보에서 제외한다.

## 4. 계속 확인되는 방식

`scripts/sync_live.sh`는 수집·색인이 끝난 뒤 다음 명령을 실행한다.

```bash
maple-chat audit-knowledge
```

결과는 append-only JSONL로 `logs/knowledge-audit.jsonl`에 누적된다. 감사 실패는 오류를 출력하지만
이미 완료된 수집·색인 결과를 무효화하지 않는다.

감사 항목:

1. 활성 `abbreviation_of` relation 목록 조회
2. 약어와 공식 전체 명칭을 포함한 활성 청크 수 집계
3. 괄호·등호형 명시적 확장 추출
4. 공식 명칭과 normalized exact comparison
5. 다른 확장 후보와 붙임형 surface를 로그에 기록

현재 감사는 read-only이며 knowledge entity/relation을 변경하지 않는다.
